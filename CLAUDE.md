# LLOYD - Local Mixologist & Bartender AI Desktop Assistant

## About the project:
A fully local, voice-activated desktop assistant (PyQt6) specialized in mixology and bartending. It listens for wake words, supports voice and text interactions, streams speech output, recognizes bottles via local vision models, provides recipes and cocktail/spirit lore, answers bar terminology questions, and compiles step-by-step visual animation guides using Manim.0
